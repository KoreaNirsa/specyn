# 00. Quickstart

실제 실행 순서와 sample-service CRUD 확인 절차는 [quickstart.md](quickstart.md) 를 기준으로 보시면 됩니다.

현재 권장 진입 경로:

1. `python specyn.py setup`
2. `python specyn.py auth-status`
3. `python specyn.py doctor`
4. `python specyn.py up -d`
5. `python specyn.py sample-up -d`
6. 필요 시 `validate -> compile-prompts -> run`
